# Test Plan: Form Builder Full Application (All 8 Feature Areas)

- **Date**: 2026-11-19
- **Stack**: React 19.3.1 + TypeScript 6.0.3 + Vite 8.3.6 + Tailwind CSS v4.3.4 + Fastify 5.12.8 + Drizzle ORM (`@neondatabase/serverless`) + Node `tsx --test` (`node:test`)
- **Scope**: `src/domain/form-schema/*`, `src/fields/*`, `src/features/{auth,builder-canvas,field-palette,form-renderer,property-inspector,schema-io,tenant-submissions}/*`, `src/shared/lib/router.ts`, `src/shared/ui/*`, `src/App.tsx`, `server/middleware/*`, `server/modules/{auth,admin,forms,submissions}/*`, `server/db/*`
- **Delete / Cleanup Support**: `Yes` (`DELETE /api/admin/tenants/:tenantId`, `DELETE /api/admin/users/:userId`, `DELETE /api/tenants/:clientId/forms/:formId`, `DELETE /api/tenants/:clientId/submissions/:submissionId`, `DELETE /api/tenants/:clientId/forms/:formId/submissions`) — Phase 4 live browser tests cleaned up all temporary tenants, forms, and submissions.
- **Triggered Conditional Classes**: Workflow State & Locks (`tenant.status`, `form.isPublished`, `user.isActive`), Relational & Foreign Keys (`clientId`, `formId`, cascade deletes, last-tenant & last-form guards), Search, Filter & Pagination (`search`, `clientId`, `formId`, `limit`, `offset`), Date & Time Boundaries (`minDate`, `maxDate`, calendar dates, session `expiresAt`), Concurrency & Idempotency (parallel slug uniqueness, idempotent seed, double-submit guard), Side Effects & Audit Trails (Resend welcome/reset-credentials emails & rollback on `502`).
- **Runners**: `test-runner (Model: "flash")`, `browser (Model: "flash")`
